# Transaction Dashboard Project

## Deskripsi
Project ini merupakan bagian dari prosedur test untuk mengikuti program magang di Sagara Tech.  
Project ini menampilkan dashboard users dan transaksi, lengkap dengan visualisasi data menggunakan Chart.js.

## Fitur
- Login menggunakan email dan password dari `../data/users.json`
- Menampilkan daftar user
- Menampilkan daftar transaksi
- Menampilkan jumlah transaksi per tanggal
- Grafik transaksi dalam bentuk **Line Chart** menggunakan Chart.js

## Teknologi
- React.js + TypeScript
- Chart.js
- JSON sebagai data dummy (`users.json` dan `transactions.json`)
